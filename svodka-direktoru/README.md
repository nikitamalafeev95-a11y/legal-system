# Сводка директору — расширение для 1С

Каждое утро руководитель получает в Telegram и/или MAX сообщение с показателями за вчера:
деньги в кассе и на счетах, выручка за день и с начала месяца, движение денег,
долги покупателей и долги поставщикам (итог и крупнейшие должники).

Поддерживаются БП 3.0 и УТ 11 / КА 2 / ERP. Вариант учета определяется автоматически.

**Статус: код написан, в 1С не запускался.** Перед продажей нужно пройти проверку из раздела «Что проверить».

## Сборка расширения (15–20 минут)

1. Конфигуратор → Конфигурация → Расширения конфигурации → Добавить.
   Имя `СводкаДиректору`, префикс `СД_`, назначение «Дополнение».
   Снять флажки «Безопасный режим» и «Защита от опасных действий».
2. Константа `СД_НастройкиСводки`, тип `ХранилищеЗначения`.
3. Общий модуль `СД_Сводка`: флаг «Сервер» включен, остальные выключены.
   Вставить текст из `src/СД_Сводка.bsl`.
4. Регламентное задание `СД_ОтправкаСводки`:
   метод `СД_Сводка.ОтправитьСводкуПоРасписанию`, «Предопределенное» включено, «Использование» выключено.
5. Обработка `СД_НастройкаСводки` с формой. Реквизиты и команды формы перечислены в шапке
   `src/СД_НастройкаСводки_Форма.bsl`; текст модуля формы — оттуда же.
   Обработку включить в подсистему «Администрирование» (заимствовать подсистему в расширение).
6. Заимствовать роль `ПолныеПрава` и дать в ней права на константу и обработку.
7. Сохранить расширение в файл `.cfe`.

## Настройка у клиента

**Telegram.** Создать бота через @BotFather, скопировать токен. Написать боту любое сообщение,
в форме настройки нажать «Найти чаты Telegram» и перенести номер чата в поле «Чаты Telegram».
Для группы — добавить бота в группу и написать в ней сообщение.

**MAX.** Создать бота на платформе MAX для партнеров, скопировать токен.
В поле «Чаты MAX» указать номер чата или `user:<номер пользователя>`.

Несколько получателей перечисляются через запятую. Кнопка «Отправить сейчас» проверяет связь.

Работа Telegram в России ограничивается с февраля 2026 года. Если сообщения не уходят,
в настройках можно указать прокси (применяется только к Telegram) или перейти на MAX.

## Откуда берутся цифры

| Показатель | БП 3.0 | УТ 11 / КА 2 / ERP |
|---|---|---|
| Деньги | сальдо Дт счетов 50, 51, 52, 55 | остатки регистров ДенежныеСредстваНаличные и ДенежныеСредстваБезналичные |
| Выручка | оборот Кт счета 90.01 (с НДС) | оборот регистра ВыручкаИСебестоимостьПродаж |
| Движение денег | Дт 50–55 / Кт 62 и Дт 60 / Кт 50–55 | приход и расход денежных регистров (включая внутренние перемещения) |
| Нам должны | сальдо счета 62, свернутое по контрагенту | положительные остатки регистра РасчетыСКлиентами |
| Мы должны | сальдо счета 60, свернутое по контрагенту | положительные остатки регистра РасчетыСПоставщиками |

Данные берутся по всем организациям базы.

## Что проверить

Эти места написаны по памяти о структуре типовых конфигураций и требуют сверки в реальной базе:

- [ ] УТ/КА/ERP: имена ресурсов. Код ищет `СуммаРегл`, затем `СуммаУпр`, затем `Сумма`
      (для выручки `СуммаВыручкиРегл`, затем `СуммаВыручки`). Если в регистре расчетов есть только
      `Сумма`, она в валюте взаиморасчетов, и при валютных договорах итог будет смешанным.
- [ ] УТ/КА/ERP: знак остатка в `РасчетыСПоставщиками` (ожидается: плюс — наш долг поставщику).
- [ ] УТ/КА/ERP: путь к контрагенту `АналитикаУчетаПоПартнерам.Контрагент`.
- [ ] БП: суммы сходятся с оборотно-сальдовой ведомостью по счетам 50–55, 60, 62, 90.01.
- [ ] Регламентное задание из расширения появляется в списке заданий и срабатывает по расписанию
      (в файловой базе — только пока открыт хотя бы один сеанс).
- [ ] MAX: формат запроса (`POST platform-api.max.ru/messages?chat_id=…`, токен в заголовке
      `Authorization`, тело `{"text", "format": "html"}`) сверить с документацией на dev.max.ru.
- [ ] Версия платформы не ниже 8.3.14 (объекты с данными в расширениях).

## Известные ограничения первой версии

- Токены хранятся в константе в открытом виде; доступ к ней есть только у роли «Полные права».
- Нет отбора по организации и нет раздела «Остатки ниже минимума».
- Не поддерживаются УНФ и Розница.
