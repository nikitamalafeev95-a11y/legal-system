# Подсказчик для внедренца 1С

По медиа-клавише снимает активное окно (окно удалённого подключения), отправляет снимок в Claude через Claude Code (`claude -p`, вход по подписке) и показывает подсказку из 1-3 строк в окне поверх всех окон. Окно подсказок не видно при демонстрации экрана и на снимках.

- `run.bat` - запуск, `check.bat` - проверка установки с тестовым запросом.
- `config.json` - клавиши, ширина снимка, модель, длина истории, шрифт.
- `task.txt` - описание задачи клиента, подставляется в каждый запрос.
- `script.txt` - скрипт встречи и материалы по клиенту (создаётся кнопкой «Скрипт»), идёт в системную часть запроса и кэшируется.
- `system_prompt.txt` - инструкция для модели.
- `Пособие.docx` - установка и использование по шагам.

Нужны Windows 10 (2004+) или 11, Python 3.10+, Pillow, Claude Code с входом по подписке.

Тесты логики: `python -m unittest discover tests`.
